#### A one-page launcher with an RSS feed.
**Minimal, feature-rich, different.**

This is not your typical pixel launcher. posidon launcher was built from scratch, to be a different experience.

- **Minimal**: There are constant improvements and optimizations in the UX, to make all of the settings as easy to understand as possible.
- **Feature-rich**:
  - Dock supports up to 7 columns and 3 rows of icons
  - News & Notifications feed
  - Vector and animated iconpack support
  - App search with contacts and shortcuts
  - Wallpaper gallery (all wallpapers are exclusive)
  - 6 Font options
  - Blur behind app drawer
  - Customizable gestures and themes
  - Widgets support
  - And much more
- **Different**: This launcher doesn't have pages, it has a scrollable feed. It's UI was inspired by One UI & elementary OS.

posidon launcher is a nonprofit project, so I won't always be able to fix everything by myself. If you want to help posidon launcher become better, please report any bugs at [t.me/posidonlauncher](https://t.me/posidonlauncher) or contribute to the code.

## Features

### Core Features
- **One-page design**: No swiping between pages, everything in a scrollable feed
- **App drawer**: With blur effect and customizable layout
- **Dock**: Highly customizable with up to 7x3 icons
- **Search**: Integrated search for apps, contacts, and web results
- **Feed**: RSS news feed and notifications display

### Customization
- **Themes**: Multiple theme options and accent colors
- **Icon packs**: Support for vector and animated icon packs
- **Fonts**: 6 different font choices
- **Wallpapers**: Built-in exclusive wallpaper gallery
- **Gestures**: Customizable swipe gestures
- **Widgets**: Support for Android widgets
- **Folders**: Customizable app folders

### Advanced
- **Notifications**: Display notifications in the feed
- **News**: RSS feed integration
- **Backup/Restore**: Settings backup and restore
- **Developer options**: Advanced customization for developers

## Building from Source

### Prerequisites
- Android Studio Arctic Fox or later
- JDK 11 or later
- Android SDK API 31

### Build Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/leoxshn/posidonLauncher.git
   cd posidon-revamped
   ```

2. Open the project in Android Studio

3. Build the APK:
   ```bash
   ./gradlew assembleRelease
   ```

The APK will be generated in `app/build/outputs/apk/release/`

## Dependencies

All dependencies are open-source:
- AndroidX libraries
- Custom libraries: android.loader, android.convenienceLib, android.launcherUtils
